# dj-proxmox: Централизованная панель управления Proxmox VE и Proxmox Backup Server

**dj-proxmox** — это веб-платформа корпоративного уровня для администрирования, мониторинга и автоматизации инфраструктуры на базе гипервизоров **Proxmox Virtual Environment (PVE)** и хранилищ резервных копий **Proxmox Backup Server (PBS)**.

---

## Назначение проекта

Проект предназначен для системных администраторов, DevOps-инженеров и провайдеров инфраструктуры, которым требуется:
- Объединить разрозненные независимые серверы и кластеры Proxmox VE в единую точку управления.
- Управлять инфраструктурой резервного копирования Proxmox Backup Server (PBS), включая контроль целостности данных и политики ротации.
- Обеспечить удаленное управление нодами Proxmox, расположенными в закрытых контурах или за NAT, без необходимости постоянной настройки внешних IP и VPN.
- Автоматизировать жизненный цикл виртуальных машин (QEMU/KVM) и контейнеров (LXC), включая шаблонизацию и инициализацию через Cloud-Init.
- Получать детализированную телеметрию и метрики производительности в режиме реального времени через Prometheus и Grafana.

---

## Архитектура и стек сервисов

Стек `docker-compose.yml` включает в себя:
1. **`core`** (`melnikovit/dj-proxmox:latest`) — Ядро управления (Go backend + React SPA frontend).
2. **`db`** (`postgres:16-alpine`) — База данных метаданных хостов, пользователей, аудита и зашифрованных токенов.
3. **`prometheus`** (`prom/prometheus:v2.55.1`) — Сбор метрик с поддержкой dynamic File Service Discovery (`promsd`).
4. **`grafana`** (`grafana/grafana:11.3.0`) — Готовые дашборды мониторинга (PVE Overview, Hosts, VMs/LXC).

### Порты сервисов по умолчанию

| Сервис | Порт | Переменная в `.env` | Описание |
| :--- | :--- | :--- | :--- |
| **dj-proxmox Web UI & API** | `8091` | `DJPROXMOX_PORT` | Главный веб-интерфейс и API ядра |
| **Grafana** | `3003` | `GRAFANA_PORT` | Дашборды мониторинга гипервизоров и виртуальных машин |
| **Prometheus** | `9093` | `PROMETHEUS_PORT` | Prometheus TSDB и сбор телеметрии |

## Быстрый старт

### 1. Клонирование и настройка окружения

```bash
# Скопируйте файл переменных окружения
cp .env.example .env

# Отредактируйте .env, задав надежные пароли и секретные ключи:
# - POSTGRES_PASSWORD
# - ADMIN_PASSWORD
# - JWT_SECRET
# - DJPROXMOX_SECRETS_KEY
# - GRAFANA_ADMIN_PASSWORD
nano .env
```

### 2. Запуск сервисов

```bash
docker compose up -d
```

### 3. Доступ к интерфейсу

- **Веб-панель dj-proxmox**: `http://localhost:8091` (Логин: `admin`, Пароль: из `.env`)
- **Grafana**: `http://localhost:3003` (Логин: `admin`, Пароль: из `.env`)
- **Prometheus**: `http://localhost:9093`

## Ключевые функциональные возможности

### 1. Управление виртуальными машинами и контейнерами
- **Полный жизненный цикл**: Создание, запуск, корректная остановка (ACPI shutdown), форсированное выключение (stop/kill), перезагрузка, приостановка (suspend/resume) и удаление VM (QEMU) и LXC-контейнеров.
- **Конфигурация ресурсов**: Горячее и статическое изменение CPU (cores, sockets, CPU units), оперативной памяти (ballooning, min/max RAM), дисковых контроллеров (VirtIO SCSI, IDE, SATA) и сетевых интерфейсов (VirtIO, VLAN tagging, firewall rules).
- **Массовые операции**: Групповой запуск, остановка и управление гостевыми системами по тегам или принадлежности к пулам.

### 2. Шаблонизация и Cloud-Init
- **Управление шаблонами**: Конвертация виртуальных машин в шаблоны (Templates) и быстрое развертывание новых инстансов.
- **Связанные и полные клоны**: Поддержка быстрого связанного клонирования (Linked Clones) на поддерживаемых хранилищах (ZFS, Ceph RBD, LVM-Thin) и полного клонирования (Full Clones).
- **Встроенный генератор Cloud-Init**: Автоматическая передача сетевых настроек (IPv4/IPv6, gateway, DNS), учетных записей пользователей, SSH-ключей и пользовательских скриптов инициализации (custom user-data) при создании машин.

### 3. Интеграция с Proxmox Backup Server (PBS)
- **Мониторинг Datastores**: Отображение доступного пространства, дедупликации, компрессии и статуса хранилищ PBS.
- **Задания резервного копирования**: Управление расписаниями бэкапов, просмотр журналов выполнения и статусов snapshot-ов.
- **Верификация и обслуживание**: Запуск и мониторинг задач проверки целостности (Verify Jobs), усечения устаревших копий (Prune Jobs) и сборки мусора (Garbage Collection).

### 4. Снимки состояния (Snapshots) и VZdump
- **Дерево снимков**: Создание моментальных снимков состояния памяти (RAM) и дисков гостевых систем.
- **Безопасный откат**: Визуальный выбор точки восстановления и мгновенный откат к требуемому состоянию.
- **Управление локальными бэкапами (VZdump)**: Создание сжатых резервных копий (LZO, GZIP, ZSTD) с сохранением на локальные и сетевые хранилища (NFS, CIFS, Directory).

### 5. Интерактивные веб-консоли
- **Прямой доступ к экрану**: Встроенная поддержка веб-консолей noVNC и SPICE для графического управления виртуальными машинами прямо в окне браузера.
- **TermProxy и Shell**: Интерактивная терминальная сессия к хосту Proxmox и гостевым LXC-контейнерам через Proxmox TermProxy.

### 6. Управление сетевой инфраструктурой и хранилищами
- **Сетевые интерфейсы**: Просмотр и редактирование Linux Bridges (`vmbr*`), Bond-интерфейсов, VLAN-интерфейсов и Open vSwitch (OVS).
- **Инвентарь хранилищ**: Мониторинг локальных и распределенных хранилищ (Directory, LVM, LVM-Thin, ZFS, Ceph RBD, CephFS, NFS, GlusterFS, iSCSI).

### 7. Сводный обзор инфраструктуры (Fleet Management)
- **Единая панель мониторинга**: Агрегированное представление состояния всех подключенных кластеров и одиночных серверов.
- **Утилизация мощностей**: Сводная аналитика по доступным ядрам CPU, объему RAM, емкости пулов хранения и сетевой активности.
- **Поиск и фильтрация**: Глобальный поиск по всем кластерам по имени, ID гостя, IP-адресу или тегам.

### 8. Безопасность и ролевая модель
- **Шифрование данных**: Хранение API-токенов (`PVEAPIToken`, `PBSAPIToken`) и паролей в зашифрованном виде (AES-GCM).
- **Аудит безопасности**: Непрерывное протоколирование действий администраторов с фиксацией IP-адреса, времени и типа выполненной операции.
- **Изоляция прав**: Разграничение прав пользователей и сервисных учетных записей.
