### [0.1.0] - 2026-08-14
#### Добавлено
- **Мониторинг**: Полноценный стек мониторинга на базе Prometheus (v2.54.1) и Grafana (v11.2.0) в `docker-compose.yml`.
- **Дашборды**: Предустановленный дашборд `overview.json` (состояние кластера PVE, нод, CPU/RAM, дисков) и `hosts.json` с автопровижинингом.
- **Динамический Target Discovery**: Интеграция `file_sd` (`prometheus/file_sd/agents.json`, `node.json`, `cadvisor.json`) и правила алертов `rules/basic.yml`.
- **CI/CD**: Downstream-триггер для автоматической публикации публичных образов в Docker Hub (`melnikovit/dj-proxmox`) и синхронизации документации в GitHub (`melnikovit/dj-proxmox`).

### [0.1.0] - 2026-08-12 (Phases 6–8)
#### Добавлено
- **Сеть и Безопасность**:
  - Управление PVE Firewall: настройка правил фильтрации трафика на уровне кластера, конкретных нод и гостевых ВМ/LXC.
  - Программно-определяемые сети (SDN): управление зонами (Simple, VLAN, VXLAN, EVPN), виртуальными сетями (VNets) и подсетями.
- **Хранилища и Отказоустойчивость**:
  - Ceph Storage: мониторинг состояния кластера Ceph, управление OSD, пулами и мониторами.
  - High Availability (HA): настройка групп HA, приоритетов ресурсов, правил отказоустойчивости и fencing.
- **Proxmox Backup Server (PBS)**:
  - Глубокая интеграция с PBS API: запуск и расписание Prune-задач, сборка мусора (Garbage Collection - GC), верификация снапшотов.
  - Просмотр дерева снапшотов и метаданных резервных копий PBS.
- **Метрики и Аналитика**:
  - Интеграция с PVE RRD metrics API для отрисовки исторических графиков нагрузки CPU, оперативной памяти, операций ввода-вывода (IOPS) и сетевого трафика.
- **Аудит, Поиск и Безопасность**:
  - Централизованный журнал аудита действий операторов.
  - Глобальный поиск по всем сущностям кластера (ноды, ВМ, контейнеры, хранилища, сети).
  - Сканирование безопасности хостов (Security Probe Scans).
- **Инструменты автоматизации (IaC)**:
  - Генератор конфигураций Terraform для Proxmox provider.
  - Генератор Ansible playbooks для автоматизации развертывания.
  - Быстрые нативные ссылки (deep-links) в оригинальный веб-интерфейс Proxmox VE.

### [0.1.0] - 2026-08-12 (Phase 5)
#### Добавлено
- **Жизненный цикл ВМ и LXC**:
  - Двухпутевой механизм выполнения операций: прямой Proxmox REST API + fallback через защищенный агентский WSS RPC.
  - Мастер создания виртуальных машин (QEMU/KVM) и контейнеров (LXC).
  - Реконфигурация оборудования: динамическое изменение ядер CPU, памяти, добавление и отключение виртуальных дисков и сетевых адаптеров.
  - Живая миграция (Live Migration) виртуальных машин и контейнеров между нодами кластера с контролем сетевого трафика.
  - Управление виртуальными дисками: Resize, перемещение дисков между пулами хранения (Move Disk).
- **Задачи и Резервное копирование**:
  - Единый центр задач (Tasks Center) с потоковым просмотром логов UPID в реальном времени.
  - Планировщик VZdump бэкапов: создание задач резервного копирования по расписанию, выбор режима сжатия (zstd, lzo, gzip), политики хранения.
  - Восстановление ВМ и LXC из резервных копий VZdump / PBS.
- **Управление флотом (Fleet View)**:
  - Сводный список всех виртуальных машин и контейнеров по всему кластеру с бейджами статуса и потребления ресурсов.

### [0.1.0] - 2026-08-12 (Phase 1–4)
#### Добавлено
- **Консоли**:
  - WebSocket проксирование графической консоли noVNC для виртуальных машин.
  - Интерактивный терминал xterm.js для последовательных консолей (Serial Console) и хостового шелла через `termproxy` с поддержкой root password fallback.
- **Сетевое управление нод**:
  - CRUD конфигурация сетевых интерфейсов Proxmox хостов (Linux Bridge, VLAN, Bond, физические NIC).
  - Безопасное применение изменений сети через `ifupdown2` с возможностью отката при потере связи.
- **Управление контентом хранилищ**:
  - Просмотр содержимого хранилищ (ISO-образы, шаблоны VZTmpl, бэкапы, фрагменты конфигураций).
  - Загрузка ISO и шаблонов на ноды, удаление и выделение дисковых объемов.

### [0.1.0] - 2026-08-12
#### Добавлено
- Начальный импорт и релиз архитектуры **dj-proxmox**:
  - Высокопроизводительное ядро на Go (`cmd/server`) со встроенным HTTP/REST API и WebSocket-хабом.
  - React SPA веб-интерфейс на TypeScript с современной темой и отзывчивым UX.
  - Бинарный агент `dj-proxmox-agent` (`cmd/agent`) для установки на ноды Proxmox.
  - Поддержка многонодовых кластеров Proxmox VE и интеграция с Proxmox Backup Server.
  - Конвейер сборки в GitLab CI, сохранение образов в Harbor и развертывание через Docker Compose / Ansible.
